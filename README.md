# 秋ノ古城 — The Castle in Autumn

紅葉に包まれた断崖の古城を、ブラウザの中で自由に見て回れるインタラクティブな3Dシーンです。

**▶ デモ: https://tanuu5.github.io/autumn-castle/**

> 🤖 このプロジェクトは **Claude**（Anthropic）が制作しました。使用モデルは **Claude Opus 5.5** です。
> コード・テクスチャ・音はすべて Claude がプログラムで生成しています。

## 特徴

- **古城**：尖頭アーチの窓、バラ窓、奥へ段々に下がる入口、円錐屋根の塔（大小7本）、中央塔、控え壁と小尖塔、はためく旗
- **周囲の景観**：断崖の台地、石畳の前庭、欄干付きの石橋、円形の展望テラス、かがり火と外灯
- **秋の空気感**：風に揺れる紅葉の木々と低木、木から舞い落ちて地面に積もる落ち葉、紅葉の森が広がる谷、雪をかぶった山並み、靄、鳥、谷底の温室
- **四季の切り替え**：春（桜と新緑、舞う花びら）・夏（深緑）・秋（紅葉と落ち葉）・冬（葉を落とした木々と積雪）。タイトルも「春ノ古城」のように変わります
- **天気**：晴・曇・雨・嵐・霧・雪。雨で石畳が濡れて光り、嵐では稲妻と雷鳴、雪の日は少しずつ積もっていきます
- **時刻の変化**：朝から夜まで光と空の色が連続して変わり、夕暮れには窓に灯りがともり、夜は星と月が現れます
- **環境音**：風・葉ずれ・雨・雷・鳥・虫の声を Web Audio でその場で合成（音声ファイル不使用）

画像・3Dモデル・音声などの外部アセットは一切使っていません。

## 操作方法

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 視点を回す |
| ホイール / ピンチ | 寄る・引く |
| クリック | 突風を起こし、落ち葉を舞い上げる |
| 時刻スライダー / 朝・昼・午後・黄昏・夜 | 時間帯を変える |
| 季節（春・夏・秋・冬） | 季節を切り替える |
| 天気（晴・曇・雨・嵐・霧・雪） | 天気を切り替える |
| 風スライダー | 風の強さ（凪〜疾風） |
| 周遊 | 操作しないでいるとカメラがゆっくり城を周回 |
| 時の流れ | 時間を自動で進める |
| 落ち葉 / 音 | 落ち葉・環境音のオン／オフ |
| 撮影 | 今の景色をPNGで保存 |
| `H` キー | UIを隠す |

## ローカルで動かす

ビルドは不要です。静的ファイルを配信するサーバーがあれば動きます（ES Modules を使うため、`file://` で直接開くことはできません）。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。Three.js とフォントは CDN から読み込むため、ネット接続が必要です。

## 技術スタック

- [Three.js](https://threejs.org/) r170（CDN・import map で読み込み）
- ポストプロセス：UnrealBloom ＋ 独自のカラーグレーディング／ビネット
- 空：独自シェーダー（雲・太陽・星・月）、PMREM による環境光
- 地形・岩山：シンプレックスノイズによるプロシージャル生成
- 樹木：葉カードのインスタンシング描画と、頂点シェーダーによる風揺れ
- 音：Web Audio API による合成
